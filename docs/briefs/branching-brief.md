## 3. Every check `tools/quest_audit.gd` runs today

| Category/check | Assertion | Severity |
|---|---|---|
| Outcome count | Each registered quest has at least two distinct fingerprints of state writes + ledger events (falling back to id). (`tools/quest_audit.gd:133-148`; `tools/quest_audit.gd:198-213`) | Warning. (`tools/quest_audit.gd:203-206`) |
| Resolution writes | Every parsed resolution has at least one state write or ledger event. (`tools/quest_audit.gd:215-224`) | Error. (`tools/quest_audit.gd:219-223`) |
| Main read-back | Every main resolution is found in later read-back sources. (`tools/quest_audit.gd:226-236`) | Error. (`tools/quest_audit.gd:230-235`) |
| Side read-back | Each missing side read-back is recorded, and aggregate resolution coverage must be ≥0.60. (`tools/quest_audit.gd:237-259`) | Missing item info; below-threshold aggregate error. (`tools/quest_audit.gd:240-258`) |
| Orphans | Written-never-read and read-never-written literal sets are compared. (`tools/quest_audit.gd:1048-1068`) | Writer-only warning; reader-only error. (`tools/quest_audit.gd:261-273`) |
| Grammar | Nonlegacy literals must be lowercase/underscore, contain no dot, and split under a registered longest-prefix domain; `%` templates are skipped. (`tools/quest_audit.gd:391-451`) | Warning. (`tools/quest_audit.gd:276-283`) |
| Phase reachability | A quest-critical NPC with an `NpcRoutines` row must be present in at least two phases. (`tools/quest_audit.gd:501-515`) | Error. (`tools/quest_audit.gd:285-291`) |
| Checked response resolve | Every dialogue response containing `[if ... check(` must call `SkillCheck.resolve` in its indented branch. (`tools/quest_audit.gd:1071-1104`) | Error. (`tools/quest_audit.gd:1100-1104`) |
| Checked response outcomes | Both success and same-indent failure branches must continue. (`tools/quest_audit.gd:1106-1139`) | Error. (`tools/quest_audit.gd:1133-1139`) |
| Acquisition softlock | A checked quest response must have an alternate response route; static token/indent analysis supplies the answer. (`tools/quest_audit.gd:1141-1150`) | Warning. (`tools/quest_audit.gd:1146-1149`) |
| Quest template | `.tres` has `quest_name`, either `quest_giver` or `giver_actor_id`, and objectives for `FlagQuest`/`DomSideQuest`. (`tools/quest_audit.gd:858-905`) | Missing field warning. (`tools/quest_audit.gd:865-875`) |
| Location template | Location scene exists, arrival flag passes grammar, and nondefault spawn aliases resolve. (`tools/quest_audit.gd:907-939`) | Missing scene/unaliased spawn error; arrival grammar warning. (`tools/quest_audit.gd:914-938`) |
| Encounter template | No `docs/templates/encounter.md` field is checked by `template_conformance_violations`, whose inputs are only quest and location source maps. (`tools/quest_audit.gd:858-878`) | No finding category exists for encounter-template fields. (`tools/quest_audit.gd:182-191`) |
| Declared template fields | Location template declares id, scene, gameplay, spawn, arrival, and thinning fields; encounter template declares Pandora combatants/defeated flag/win-loss ledger rows, catalog board/weather/spoils, placement gate, and speech hooks; side template declares resource identity/giver/participants/hooks/dialogue/resolution/outcome/Agreement fields. (`docs/templates/location.md:21-32`; `docs/templates/encounter.md:16-42`; `docs/templates/side-quest.md:18-46`) | Only the quest/location subset above is mechanically validated. (`tools/quest_audit.gd:858-939`) |
