## Decisions taken while implementing

- **Gate values are stated, not blank.** The handoff's example shows `"locked_message": ""` for an
  ungated door. The runtime value of an ungated door is the script default "This door is locked.",
  so canon states that; the bake omits any gate equal to its default, which is what the
  hand-written files did. Value identity wins over the example.
- **The exit object holds five values**, adding `source_position` to the handoff example: the exit's
  position is authored per interior and cannot be derived.
- **Exits carry no gates.** None of the 24 do; the exit object refuses gate keys rather than
  inventing an override slot no data needs.
- **List order** follows the index (interiors by location id). Only `by_id()` is used at runtime,
  so no behaviour depends on it.
- **The canonical-text test validates all canon together**: a door's source scene belongs to another
  document, so validating one file alone now fails by design.
