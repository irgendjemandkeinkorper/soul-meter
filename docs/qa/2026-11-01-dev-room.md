## Status

Implementation and acceptance coverage are present. Manual-save protection is
unresolved: the existing sandbox suppresses autosaves, but `SaveGame.save()`
and `save_to_slot()` bypass it. The integration test intentionally detects this
by hashing disposable fixture slots before and after attempted dev-session saves.
No real player files were used.

The requested scope exception is a guard at the beginning of
`globals/save_game.gd::_write_current_payload()`:

```gdscript
if runtime_sandbox_is_armed():
    return false
```

That reuses the existing sandbox and requires no new save-system design. The
file is outside the approved scope; this change has not been applied while the
approval question is pending.
