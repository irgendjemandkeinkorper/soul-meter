# SoulMeter

A game built in **Godot 4**.

## Run

Open `project.godot` in Godot 4.7+ (Editor → Import), then press Play.

## Structure

- `project.godot` — Godot project config
- `*.tscn` — scenes
- `icon.svg` — app icon

> The `.godot/` build/shader cache is gitignored — it's regenerated on open.
