Fonts per the Soul Meter Design System (design/DESIGN_SYSTEM.md): Cinzel (display,
inscriptional labels), Cormorant Garamond + Italic (body, dialogue, flavour quotes),
Fira Code (numerals only — "the mono face is the ledger, not the interface"),
Metamorphous (display-alt). All from github.com/google/fonts, SIL Open Font License 1.1.
The DS notes these are Google-Fonts substitutions for unsupplied brand binaries — swap
when licensed originals arrive.
